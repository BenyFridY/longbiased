## Features Removed (bottom-8 by gain importance)

From the 37 features in V25_FINAL, these 8 ranked lowest in XGBoost gain importance:

1. `hash_rate_pctchg_30d` — 0.0155
2. `price_percentile_1y` — 0.0170 (historically flagged as high-signal in V06; no longer)
3. `ou_theta_60d` — 0.0182
4. `obv_trend` — 0.0191
5. `macd_histogram` — 0.0200 (scale varies with price level)
6. `trend_strength` — 0.0207 (= adx × hurst_30d, correlated with adx)
7. `miners_revenue_ratio` — 0.0208
8. `vol_x_regime_duration` — 0.0212

(2 derived features `ret_3d` and `ret_10d` also in bottom-10 but they're generated by build_ml_features, not stored in the 37.)

Remaining: **29 features** (37 − 8).

---

## Fracdiff d: 0.5 → 0.3

- d = 0 → original series (full memory)
- d = 1 → full differencing (returns, memoryless)
- d = 0.5 → halfway (V25 current)
- d = 0.3 → more memory preserved

On BTC log prices: d=0.3 keeps the trending behavior close to price, d=0.5 detrends more aggressively. Apparently the model extracts more signal from preserving memory.

---

## Known Limitations (still present)

1. **Friday overfit invariant**: all techniques leave the 62% Fri vs 52-55% other-days gap. Fri signal structure appears robust to ML choices. Rebalance in other days / multi-day rebal all degrade Sortino. Component of Fri alpha is likely period-specific (2022-2026).

2. **Rolling window worse than expanding**: historical 2019-2020 data still informative despite regime differences. BTC early bull-run patterns help.

3. **Regularization hurts**: even mild reg α=0.1 degrades 0.13-0.16 Sortino. XGBoost with colsample_bytree=0.5 + min_child_weight=12 already controls overfitting.
